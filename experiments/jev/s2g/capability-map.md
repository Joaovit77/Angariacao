# Matriz capacidade × evidência

Cada capacidade recebe exatamente uma categoria, definida antes do mapa. Permissão atual: NONE. Classes A/B/C só descrevem efeito possível depois de novo gate; D/E ficam no nível 0. Confidence HIGH/MEDIUM/LOW é da análise de evidência, nunca do JEV.

| Categoria | Definição |
| --- | --- |
| A — APTA_PARA_EXPERIMENTO_DE_PRODUTO | Evidência sintética suficiente para propor experimento isolado futuro, sem autonomia crítica, sob feature flag e shadow; não certifica produção. |
| B — APTA_COM_GUARDA_DE_CODIGO | Sinal do JEV só pode contribuir se regras determinísticas independentes confirmarem ou limitarem a saída antes de qualquer efeito; guarda não é confidence do modelo. |
| C — SOMENTE_ASSISTIVA | Somente sugestão, alerta, ranking ou explicação sujeitos a revisão; não comanda efeito operacional. |
| D — NAO_PROMOVER | Erro material ou inconsistência observada impede promover esta função no contrato atual. |
| E — NAO_AVALIADA | Falta evidência direta suficiente para esta função/domínio. Não significa desempenho bom ou ruim e não permite generalização por analogia. |

Todas as referências por ID resolvem no [evidence ledger](evidence-ledger.json), com caminho/hash/pointer e limitações. A coluna de amostra mostra o recorte primário, não uma soma; [JSON completo](capability-map.json) registra amostras de todas as referências separadamente. Módulos A–P estão no [mapa de módulos](angario-module-map.md). Efeitos permitidos são exclusivamente para futuros experimentos aprovados; E0 abaixo significa nenhum efeito.
